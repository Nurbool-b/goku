QAZGAME: агенты для компьютеров клуба
======================================
ВАЖНО: в этой папке секретные ключи клуба. Не загружайте её на GitHub и не отправляйте клиентам.

Содержимое
- pc_agent.py        : служба на каждом ПК (выключить / перезагрузить по команде из админ-панели). Работает от SYSTEM.
- lock_screen.py     : экран блокировки на каждом ПК (работает в сессии пользователя).
- wol_agent.py       : ОДИН агент на постоянно включённом устройстве в сети клуба (включает ПК по сети, Wake-on-LAN).
- configs\PCxx\      : ключи каждого ПК (agent_config.json, lock_config.json).
- install_pc.bat, install_wol_agent.bat : установка с автозапуском.

Как работает
1. Оператор подтверждает заявку -> ПК включается по сети -> на экране блокировки "Забронировано".
2. Клиент вводит 4-значный код со страницы заявки -> экран скрывается, запускается таймер тарифа.
3. За 5 минут до конца таймер краснеет. По окончании экран блокируется, через 2 минуты ПК выключается сам.
4. Если клиент не пришёл 30 минут, бронь снимается автоматически.
5. Оператор может разблокировать вручную, продлить или завершить сессию в админ-панели.

Установка на КАЖДЫЙ ПК (около 5 минут)
1) Установите Python 3 с python.org. Отметьте "Add python.exe to PATH" и оставьте tcl/tk.
2) Скопируйте на ПК всю эту папку (флешкой). Запустите install_pc.bat ОТ ИМЕНИ АДМИНИСТРАТОРА.
3) Введите номер ПК (как в админ-панели). На вопрос про экран блокировки: n для проверки, y для рабочего режима.
4) Перезагрузите ПК. Через минуту ПК должен стать "онлайн" во вкладке "Устройства" админ-панели.

Один раз на постоянно включённом устройстве (ПК оператора)
Запустите install_wol_agent.bat от администратора (рядом должны лежать wol_agent.py и wol_config.json).

Wake-on-LAN на каждом ПК (один раз)
- ПК подключён кабелем (не Wi-Fi).
- BIOS: включить Wake on LAN / PME Event Wake Up / Power On By PCI-E; если есть ErP - выключить.
- Windows: Диспетчер устройств -> сетевой адаптер -> Свойства: Управление электропитанием (разрешить пробуждение, только magic packet), Дополнительно: Wake on Magic Packet = Enabled.
- Электропитание -> Действие кнопок питания -> отключить "Быстрый запуск".
Работает не на всех платах. Проверьте на 2-3 ПК раньше.

Безопасность
- Экран блокировки "мягкий": клиент с правами администратора Windows может закрыть его через Диспетчер задач. Для клиентов используйте обычную учётную запись Windows с автоматическим входом, оператору - отдельную админ-учётную запись.
- Нужен интернет: без связи с сервером ПК остаётся заблокированным.
- Секрет службы (agent_config.json) доступен только SYSTEM и администраторам.
