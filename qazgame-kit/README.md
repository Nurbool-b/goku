# QAZGAME — компьютерлік клубқа арналған жинақ (kit)

Бір файлдан (`club.json`) әр клубқа дайын сайт, оператор панелі, база деректері және компьютерге арналған агенттер шығарады.

## Жаңа клубты 30 минутта қосу
1. **Supabase жобасы:** supabase.com → New project (клубқа бір жоба). Project URL мен `anon` кілтін көшіріп алыңыз (Settings → API).
2. **Баптау файлы:** `club.example.json` файлын `club.json` деп көшіріп, ішін толтырыңыз (төменде кесте).
3. **Генерация:** `python make_club.py club.json` (Python 3 керек). `dist/<клуб-аты>/` папкасында шығады: `index.html`, `admin.html`, `seed.sql`, `<клуб-аты>-agents.zip`.
4. **База:** Supabase → SQL Editor: алдымен `schema.sql`, содан кейін `seed.sql` файлының мазмұнын іске қосыңыз.
5. **Әкімші аккаунты:** Authentication → Users → Add user → `admin_email` поштасымен, **Auto Confirm User** қосып. Ол өзі әкімші болады.
6. **Сайт:** `index.html` және `admin.html` файлдарын GitHub Pages-ке жүктеңіз. Админ панель: `.../admin.html`.
7. **Компьютерлер:** `<клуб-аты>-agents.zip` ішіндегі `README.txt` бойынша орнатыңыз.

## club.json өрістері
| Өріс | Мағынасы |
|---|---|
| `name`, `logo_top`, `logo_accent` | клуб аты; логотип мәтіні (`logo_accent` түсті болады) |
| `city`, `address`, `tagline` | `ru` және `kk` мәтіндер |
| `open24` | `true` болса, «24/7» мәтіндері өзі шығады; әйтпесе `hours`, `hours_short`, `hours_note`, `hours_big` беріңіз |
| `phone`, `whatsapp` | `+7…` және тек сандар (чек WhatsApp-қа осы нөмірге барады) |
| `instagram`, `twogis`, `rating` | міндетті емес. `twogis` болмаса, «Пікірлер» бөлімі жасырылады |
| `colors` | `brand`, `dark`, `bg`, `card`, `text`: сайт пен панель түстері |
| `zones[]` | `id` (латын әріп), `name`, `count`, `specs` (сипаттамалар: CPU, GPU, Monitor…) |
| `tariffs` | әр аймаққа баға: `hour` міндетті, қалғаны `p21`, `p32`, `morning`, `day`, `night` |
| `school`, `bonus` | міндетті емес (мектеп тарифі, толықтыру бонусы) |
| `rules` | ережелер тізімі, `ru` және `kk` |
| `supabase`, `admin_email` | жоба URL/кілті және әкімші поштасы |
| `kaspi`, `powered_by` | Kaspi сілтемесі (бастапқыда қосымшаның басты экраны); `powered_by: false` болса, төменгі «Powered by QAZGAME» жазуы жоғалады |

## Ескертулер
- Әр клубқа **өз Supabase жобасы** керек, сонда клубтар бір-бірінің деректерін көрмейді. Тегін тарифте белсенді жоба саны шектеулі: нақты шекті аккаунтыңызда тексеріңіз.
- `seed.sql` мен агенттер архивіндегі кілттер **бірге** жасалады. Генераторды қайта іске қосқан сайын кілттер жаңарады: сондықтан `seed.sql` мен архивті бір жолы пайдаланыңыз. Қайта іске қосып жаңа архив алсаңыз, базаны да жаңадан (`schema.sql` + жаңа `seed.sql`) құру керек.
- Агенттер архивінде құпия кілттер бар: GitHub-қа жүктемеңіз.
- Өшірулі компьютерді қосу кабель мен платаның Wake-on-LAN қолдауына байланысты. Алдымен 2–3 компьютерде сынаңыз.
- Kaspi төлемін автоматты тексеру жоқ: оператор WhatsApp-тағы чекті қолмен тексереді.

## Құрылымы
`make_club.py` генератор · `schema.sql` база схемасы · `template/` сайт, панель және агенттер үлгілері · `club.example.json` бос баптау · `samples/` мысалдар (goku eSports, Cyber Arena).
