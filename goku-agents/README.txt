GOKU CONTROL: агенты и экран блокировки
========================================
ВАЖНО: в архиве секретные ключи. НЕ загружайте его на GitHub.

Что внутри
- pc_agent.py        : служба на каждом ПК (выключить / перезагрузить по команде из админ-панели). Работает от SYSTEM.
- lock_screen.py     : экран блокировки на каждом ПК (работает в сессии пользователя).
- wol_agent.py       : ОДИН агент на постоянно включённом устройстве в сети клуба (включает ПК по сети).
- configs\PCxx\      : для каждого ПК: agent_config.json (секрет службы) и lock_config.json (отдельный слабый ключ для экрана блокировки).
- install_pc.bat, install_wol_agent.bat : установка с автозапуском.

Как это работает
1. Оператор подтверждает заявку -> ПК включается по сети (Wake-on-LAN) -> на экране блокировки "Забронировано".
2. Клиент вводит 4-значный код со страницы заявки -> экран скрывается, запускается таймер тарифа (время идёт с момента ввода кода).
3. За 5 минут до конца таймер краснеет. По окончании экран блокируется, через 2 минуты ПК выключается сам.
4. Если клиент не пришёл 30 минут, бронь снимается автоматически.
5. Оператор может разблокировать вручную, продлить или завершить сессию в админ-панели.

Установка на КАЖДЫЙ ПК
1) Python 3 (python.org), при установке отметьте "Add python.exe to PATH" и оставьте включённым tcl/tk.
2) Создайте папку, положите туда: pc_agent.py, lock_screen.py, install_pc.bat и два файла из configs\PCxx\ ЭТОГО ПК (agent_config.json, lock_config.json).
3) Запустите install_pc.bat от имени администратора, затем перезагрузите ПК.
4) Через минуту агент сам отправит MAC-адрес в базу (нужен для включения по сети). Проверьте в админ-панели: вкладка "Устройства".

Установка на ОДНО постоянно включённое устройство
Скопируйте wol_agent.py, wol_config.json, install_wol_agent.bat, запустите install_wol_agent.bat от администратора.

Настройка Wake-on-LAN на каждом ПК (один раз)
- BIOS: включить "Wake on LAN" / "Power On By PCI-E".
- Windows: Диспетчер устройств -> сетевой адаптер -> Свойства: "Управление электропитанием" (разрешить пробуждение, только magic packet) и "Дополнительно" -> Wake on Magic Packet = Enabled.
- Панель управления -> Электропитание -> "Действие кнопок питания" -> отключить "Быстрый запуск".
- ПК подключён кабелем (не Wi-Fi).

Безопасность (важно)
- Экран блокировки "мягкий": клиент с правами администратора Windows может закрыть его через Диспетчер задач. Для клиентов используйте обычную учётную запись Windows (не администратор), вход под ней автоматический. Оператору - отдельная админ-учётная запись.
- Для работы нужен интернет: без связи с сервером ПК остаётся заблокированным и просит позвать оператора.
- Секрет службы (agent_config.json) доступен только SYSTEM и администраторам.

Проверка без админ-панели (Supabase -> SQL Editor), 5 = номер ПК
  insert into commands(pc_id, action) values (5, 'wake');
  insert into commands(pc_id, action) values (5, 'shutdown');
Команды живут 2 минуты. Проверьте сначала на 2-3 компьютерах.
